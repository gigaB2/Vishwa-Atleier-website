## Management Suite Quick Setup

To configure a new database instance for the Management Suite:
1. Create a Supabase project at [supabase.com](https://supabase.com).
2. Execute the 1-click database schema: [`management suite/assets/supabase-schema.sql`](management%20suite/assets/supabase-schema.sql).
3. Set your project URL and public Anon key in [`management suite/assets/config.js`](management%20suite/assets/config.js) or via **Admin Settings** inside the app.
4. For complete instructions, see the [Management Suite README](management%20suite/README.md).
